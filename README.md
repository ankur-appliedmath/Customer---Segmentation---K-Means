# Customer-Segmentation-K-Means
# Customer Segmentation Analysis using K-Means Clustering

## Overview

This project presents a customer segmentation analysis using the K-Means clustering algorithm implemented in **R**.

The objective is to group customers based on **Annual Income** and **Spending Score** to identify meaningful customer segments that can support business decision-making and targeted marketing.

## Features

- K-Means Clustering
- Data Preprocessing
- Feature Scaling
- Elbow Method for Optimal K Selection
- Cluster Visualization
- Mathematical Background of K-Means
- Complete R Implementation

## Tools Used

- R
- ggplot2
- K-Means Clustering
- Machine Learning
- Data Visualization

## Dataset

Mall Customer Segmentation Dataset (Kaggle)

## Repository Contents

- Customer_Segmentation_Mini_Project.pdf

## Results

The Elbow Method identified **5 optimal clusters**, representing different customer groups based on income and spending behaviour.
